Office Attendance Tracker — Windows Server Manual

Complete Installation, Office LAN Setup, Login Credentials & Data Anti-Tampering Security Guide (v2.4)

1. Included Standalone Windows Software Files (.EXE)

This package includes two self-contained Windows executables that require zero external dependencies (no Node.js, npm, or external database installation required):

1. OfficeAttendanceTracker-Setup.exe

Guided Windows Setup Wizard — Installs the application on your main Server PC, creates Desktop & Start Menu shortcuts, configures Windows Auto-Start, and adds the LAN Firewall rule.

2. OfficeAttendanceTracker-Portable.exe

Single-File Portable Executable — Runs immediately from any folder or USB drive without installation. Launches the Windows Server Control Panel and embedded database engine.

2. Which Options to Toggle ON/OFF While Installing

Important Golden Rule: You only install OfficeAttendanceTracker-Setup.exe on ONE computer (your main Office Server PC). Do not install the server .exe on employee computers—employees connect to your server over the office network.

Right-click OfficeAttendanceTracker-Setup.exe on your Server PC, select Run as Administrator, and set the 5 checkboxes as follows:

Setup Wizard Checkbox Option Toggle Purpose & Explanation
1. Create Desktop Shortcut ("Office Attendance Tracker") ON (✓) Places the server control panel icon on the Server PC desktop for quick management.
2. Create Windows Start Menu Shortcut ON (✓) Adds the program to the Windows Start Menu.
3. Start Attendance Server automatically when Windows starts ON (✓) Essential for servers — automatically starts the server in the background whenever the PC reboots.
4. Add Windows Firewall rule for Office LAN access (Port 3000) ON (✓) Essential for LAN access — opens TCP Port 3000 in Windows Firewall so employee PCs can connect.
5. Launch Office Attendance Tracker immediately after setup ON (✓) Starts the server and opens the Server Control Panel immediately.

3. How to Make It Available on All Office Computers (LAN Guide)

Step 1: Note Your Server's Office LAN Address

  1. Open the Office Attendance Tracker — Local Windows Server Control Panel on your Server PC.
  2. Look at the green Office LAN Address (Share with Staff PCs) box (for example: http://192.168.1.100:3000).
  3. Recommended: In your Windows Network Settings or office Wi-Fi router DHCP settings, reserve that local IP address (192.168.1.100) for your Server PC so it never changes after a router reboot.

Step 2: Connect Employee Computers (Zero Installation Needed)

  1. Ensure each employee PC is connected to the same office Wi-Fi or Ethernet network as the Server PC.
  2. Open Microsoft Edge or Google Chrome on the employee PC and enter the Server's LAN URL (e.g., http://192.168.1.100:3000).
  3. Optional — Create a Native Desktop App Icon on Employee PCs:
    • Right-click on the employee's Desktop → New → Shortcut.
    • Paste the command below (replace 192.168.1.100 with your Server's LAN IP):
    "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --app=http://192.168.1.100:3000
    • Name the shortcut Office Attendance Tracker. Double-clicking it opens a dedicated, standalone Windows application window without browser tabs or address bars.

4. How to Stop People from Tampering with Data (6-Step Lockdown)

1. Change Default Admin PINs Immediately (Critical First Step)

Anyone who knows the initial Admin PINs (1234 or 5555) can open the Admin Panel. Upon first launch:

  1. Sign in as Sarah Jenkins (EMP-101 / PIN 1234).
  2. Open Employees Directory in the left sidebar.
  3. Click Edit on both Admin accounts (EMP-101 and EMP-102) and change their Kiosk Security PIN to a private 6-digit code known only to management.
  4. Remove the sample employees (EMP-103 through EMP-108) and add your actual employees with unique PINs.

2. Assign Regular Staff to the "Employee" Role Only

When creating accounts in Employees Directory, set System Permission Role to Employee (Personal Reports & Self Punch Only). Standard employees cannot edit past punches, view other staff records, change shifts, or access server settings.

3. Minimize to System Tray & Lock the Server PC Screen (Win + L)

The master database (data\database.json) resides on the Server PC. In the Server Control Panel, click Minimize to System Tray, then press Win + L to lock Windows with a password. The attendance server continues running 100% normally in the background while the screen is locked, preventing anyone from physically tampering with the server machine.

4. Prevent "Buddy Punching" with Private PINs & Lobby Kiosk

If using a shared entrance tablet or reception PC, switch it to Lobby Kiosk Mode (top title bar). Employees must enter their 4-digit PIN to punch, and exiting Lobby Kiosk Mode back to the desktop view is locked behind your secret Administrator PIN.

5. Built-In Mandatory Audit Trail for Manual Adjustments

Employees cannot modify missed punches themselves. When an Admin adjusts a punch in Team Roster & Logs → Adjust Log, the application requires a Mandatory Audit Reason and permanently stamps the record with the Admin's name and note on all CSV and PDF reports.

6. Weekly 1-Click JSON Database Backup

Once a week, log in as Admin → Office & Server Settings → click Export Full Database Backup (JSON) and store the backup file on a private drive.

Manual Windows Firewall Command (Reference)

If you ever need to manually open Port 3000 in an Administrator Command Prompt on the server:

netsh advfirewall firewall add rule name="Office Attendance Tracker" dir=in action=allow protocol=TCP localport=3000
